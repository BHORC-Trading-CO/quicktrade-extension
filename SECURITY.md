# Security reports

Report vulnerabilities privately to **support@quicktrade.skin**. Include the extension version, browser version, affected component, expected and observed behavior, and minimal steps to reproduce using test data. Do not include session cookies, access tokens, private keys, real account identifiers or personal trading records.

Do not post exploitable details in a public issue. The maintainers will assess the report and coordinate disclosure and a fix. This snapshot does not promise a response deadline or a supported release schedule.

For local investigation, use mocked marketplace responses. Do not perform purchases, mutate real listings or probe accounts you do not control. Publishing source does not grant authorization to test the hosted application or third-party marketplaces.
